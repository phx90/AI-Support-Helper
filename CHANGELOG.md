# Changelog

All notable changes to this project will be documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- GitHub issue forms, pull request checklist, security policy, and contribution guide.
- Dependabot configuration for Python, npm, Docker, and GitHub Actions.
- Reproducible frontend builds and full CI quality gates.
- Automated frontend formatting with Prettier.

## [1.0.0] - 2026-10-14

### Added

- FastAPI support platform with PostgreSQL, pgvector, Alembic, and structured logging.
- Document ingestion and evidence-grounded RAG for PDF, DOCX, Markdown, and text files.
- LangGraph support agent with knowledge retrieval, system status, and ticket tools.
- OpenAI, Anthropic, and deterministic mock providers.
- Responsive Next.js dashboard, chat, knowledge base, tickets, automation, and status views.
- Docker Compose stack, n8n workflows, tests, evaluation dataset, and technical documentation.
